U.S. Financial News Corpus and Metadata Audit

Metadata audit of a TDM Studio financial-news corpus — source coverage, schema reliability, topic and tone features, and where the publication-year gaps are.

Part of my UBC Sauder RA work on finance text and investment-research data sources.

GitHubWord cloudsTop publications

Sufficient statistics

The question
Which news sources, time periods, and metadata fields can support financial text analysis?
The data
Ten TDM Studio metadata partitions for U.S. business, finance, economics, and commercial news; each row is keyed by GOID in the 31-column metadata export.
My part
I kept raw master.csv files as the canonical input, built the partition pipeline, separated metadata audit tables from topic/tone features, and assembled the source, decade, and partition figures.
What came out
clean_metadata.parquet, metadata_topics_sentiment.parquet, summary_statistics_final.xlsx, grouped word-cloud/tone/topic figures, and a standalone raw-first EDA workbook.

Methods and stack

Methods
metadata auditing, GOID checks, publication coverage checks, raw-first EDA workbook, NMF/LDA topics, Loughran-McDonald tone, parquet exports
Tech stack
Python, pandas, Parquet, Jupyter, NLP, Loughran-McDonald
