Memory Is the Difference between Two Futures: Memory Response Paths and Path-Structured Context Compilation

With Jerrold Huang, I compare matched futures with and without one memory to trace its effect over time. In a separate 144-item evaluation, PSCC's LLM-judged quality is about 6.9 percentage points higher than A-Mem's while using roughly one-third fewer API tokens.

The manuscript and code remain private.

Manuscript · Submitted, under review · 2026

When Answers Surprise

An earnings-call answer may matter because it departs sharply from the conversation before it. With Jerrold Huang, I built an earnings-call panel to test whether that answer-level novelty predicts returns beyond earnings surprise. Time holdouts, placebo tests, and timing checks ask whether the result survives a different split or timing assumption.

This paper is coauthored with Jerrold Huang. The manuscript and code remain private.

Research assistant · UBC Sauder · Apr 2026–Present

Age-Biased Technological Change

As the sole RA on this faculty-led study, I independently compare measures of technological change and panel fixed-effects regression designs using the CPS labor survey, O*NET occupation database, and USPTO patent data. I use PatentsBERTa and Qwen for text embeddings and feature extraction. I maintain the R/Python replication package with wage and sorting models, GMM, and block bootstrap inference, and write Bash and Slurm job scripts for HPC workloads.

The project is led by J. Frank Li and Cheng Chen at UBC Sauder.

Research assistant · UBC Sauder · May 2026–Present

Financial Media Multimodal Analysis

I evaluate the coverage and reliability of financial-media data for empirical research. I matched RavenPack metadata with over 3.2 million ProQuest articles to examine publication coverage and missingness. For research on financial creators, I built a reproducible creator-video panel pipeline with multimodal assets, source tracking, and validation so sample construction can be reviewed and repeated.

I work with Allen Hu at UBC Sauder.

Data Science and Machine Learning for Social Science Teaching

I developed Python/R teaching materials for economics and sociology courses using NLP, computer vision, and time-series forecasting. I co-developed a natural language inference (NLI) tutorial on zero-shot stance classification, human-label validation, and robustness checks. I also designed and taught a computer vision workshop and coauthored a notebook using image embeddings to examine Richter's kouroi categories.

Praxis work was supervised by Jonathan Graves and Laura Nelson. The image-embedding notebook is with Yash Mali and Krishaant Pathman.
