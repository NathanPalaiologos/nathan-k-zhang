Narrative Innovation Response Functions

An event-study pipeline that turns disclosure language into out-of-fold narrative innovations, then traces how abnormal returns vary with them across event windows.

Research in progress with Jerrold Huang. This site shows only the public demo and shareable aggregate results.

Sufficient statistics

Question
After accounting for the pre-call state and earlier dialogue, which parts of earnings-call language still move with returns?
Data
Public SEC 8-K filings power the laptop demo. The paper pipeline uses a 9,626-call WRDS S&P 500 earnings-call panel linked to Capital IQ transcripts, CRSP returns, IBES estimates, and Compustat/CRSP identifiers.
What I did
I worked on the reusable `src/nirf` layer, the public 8-K demo, and the WRDS S&P 500 staging pipeline. I also wrote the paper-freeze script that bundles baseline results, diagnostics, learner-audit tables, CSVs, TeX tables, and figures.
Output
A laptop-runnable 8-K demo, a WRDS S&P 500 earnings-call pipeline, response curves, placebo and residualized-outcome checks, learner-audit tables, and a frozen paper-results package.
Methods
out-of-fold narrative innovations, forward block splits, event-window CAR, clustered inference, learner-invariance audit, placebo windows, WRDS exporter
Tech stack
Python, scikit-learn, pandas, WRDS, CRSP, IBES, Capital IQ, LaTeX
