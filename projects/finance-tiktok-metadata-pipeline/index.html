Finance TikTok Creator Metadata Pipeline

A lightweight pipeline for turning finance-creator metadata into reviewable creator and video tables.

Built for finance-media RA work; sensitive source details stay out of the public version.

Sufficient statistics

The question
How can creator and video metadata move from manual review sheets into a research dataset?
The data
Creator seeds, platform metadata, asset manifests, and manual review tables organized for finance-media research.
My part
I built a low-dependency pipeline that can run offline or with credentials, while recording missing tools and skipped steps.
What came out
Creator snapshots, video metadata tables, evidence joins, topic tags, validation summaries, and runbook documentation.
Methods
CLI workflow design, DuckDB views, metadata evidence rows, topic tags, manual review hooks, validation summaries
Tech stack
Python, DuckDB, pandas, Parquet, yt-dlp, CLI
